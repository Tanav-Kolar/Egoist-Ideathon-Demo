pHash risk gate

Imports the exact same phash.js module the app uses (no algorithm drift), computes the fingerprint of every sample, its modified copy, and the decoy, and prints the full Hamming-distance matrix. Required before building any UI — build-spec.md §8 / §12, step 2.

Must be served over HTTP (python3 -m http.server 8080 from the repo root, then open /tools/phash-check.html) — file:// taints the canvas and getImageData() will throw.
