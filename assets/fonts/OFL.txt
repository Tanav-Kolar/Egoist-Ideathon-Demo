Fonts in this directory — Geist, Geist Mono, and Instrument Serif — are distributed
under the SIL Open Font License, Version 1.1, and were downloaded from Google Fonts
(fonts.google.com) for self-hosting so the demo has no runtime dependency on a font CDN.

- Geist & Geist Mono: designed by Vercel. https://vercel.com/font
- Instrument Serif: designed by Instrument. https://github.com/Instrument/instrument-serif

Google Fonts serves Geist and Geist Mono as variable-weight files. Those were instanced
into true static per-weight woff2s with `fonttools varLib.instancer` (fvar table
dropped) before being committed here — a simplification (smaller files, no variable-font
ambiguity), not a bug fix: real Chrome renders the variable files correctly too.
Instrument Serif ships from Google Fonts as an already-static file.
